# bootstrap-agent-from-kernel

Status: `planned-not-released`.

This capability will consume a pinned Network Kernel release plus approved corpus subscriptions, compile a destination-specific baseline, run conformance, and emit a minimized bootstrap receipt. It will not read or export raw owner memory.

No destination mutation is authorized while status remains `planned-not-released`. Any future released adoption requires destination-local authority, sandboxing, positive and negative tests, a verifiable rollback procedure, and receipts before execution.
